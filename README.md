# Домашнее задание (26.11.2026)

Репозиторий содержит выполненные задания по программированию на Python, включая графический интерфейс («Урезанный FastQC») для анализа и визуализации качества FASTQ-файлов.

---

## Запуск на компьютере под управлением Linux (Ubuntu)

### 1. Скачивание репозитория
Откройте терминал (`Ctrl + Alt + T`) и клонируйте репозиторий:

```bash
git clone https://github.com
cd -26.11.26
```

---

### 2. Активация окружения Miniconda
Активируйте базовое окружение Conda (или создайте отдельное):

```bash
conda activate base
```
*(При необходимости создания нового окружения: `conda create -n fastq_env python=3.11 -y && conda activate fastq_env`).*

---

### 3. Установка зависимостей
Установите библиотеки, необходимые для построения графиков и отображения изображений:

```bash
pip install matplotlib seaborn
```
*(Если при запуске появится ошибка отсутствия `tkinter`, установите системный пакет Ubuntu: `sudo apt update && sudo apt install -y python3-tk`).*

---

### 4. Запуск графического интерфейса (FastQC GUI)
Перейдите в директорию `biological-data-formats` и запустите приложение с флагом `--gui`:

```bash
cd biological-data-formats
python3 fastq_gui.py --gui
```

**Проверка работы:**
1. В открывшемся окне нажмите кнопку **«📂 Выбрать FASTQ файл»**.
2. В окне выбора перейдите в папку `test_data` и откройте тестовый файл **`test.fastq`**.
3. В окне отобразятся количество прочтений, средняя длина и графики качества.

---
