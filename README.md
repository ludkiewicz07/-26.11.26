# Домашнее задание (26.11.2026)

Репозиторий содержит выполненные задания по программированию на Python для Linux.

## Содержание репозитория
* **`calculator.py`** — калькулятор.
* **`patiens.py`** — программа для работы с данными пациентов.
* **`biological-data-formats/fastq_gui.py`** — графический интерфейс («Урезанный FastQC») для анализа и визуализации качества FASTQ-файлов.

---

## Подготовка к запуску (Linux / Miniconda)

### 1. Скачивание репозитория
Откройте терминал (`Ctrl + Alt + T`) и клонируйте репозиторий:

```bash
git clone https://github.com
cd -26.11.26
```

### 2. Активация окружения Miniconda
Активируйте окружение Conda:

```bash
conda activate base
```
*(При необходимости создания нового окружения: `conda create -n hw_env python=3.11 -y && conda activate hw_env`).*

---

## Запуск заданий

### Задание 1. Калькулятор (`calculator.py`)
Из корневой папки репозитория (`-26.11.26`):
```bash
python3 calculator.py
```

### Задание 2. Пациенты (`patiens.py`)
Из корневой папки репозитория (`-26.11.26`):
```bash
python3 patiens.py
```

### Задание 3. Графический интерфейс FastQC (`fastq_gui.py`)

1. **Установите необходимые библиотеки** (если ещё не установлены):
   ```bash
   pip install matplotlib seaborn pandas pillow
   ```
   *(Если в системе отсутствует графическая библиотека `tkinter`, установите её командой: `sudo apt update && sudo apt install -y python3-tk`).*

2. **Запустите приложение с флагом `--gui`**:
   ```bash
   cd biological-data-formats
   python3 fastq_gui.py --gui
   ```

3. **Проверка работы интерфейса:**
   * В открывшемся окне нажмите кнопку **«📂 Выбрать FASTQ файл»**.
   * В диалоговом окне перейдите в папку `test_data` и выберите тестовый файл **`test.fastq`**.
   * На экране отобразятся статистика прочтений (количество и средняя длина) и графики качества.
